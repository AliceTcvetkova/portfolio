Personal Product Vision · AI product + automation

Reels Agent

A personal AI agent I built for @sashaiamdrawing: it knows my Level 33 rules, my iPhone + iMovie setup, and turns today’s real quests into a shoot-ready 35-second storyboard. Not a product for “all creators” — dogfooding a problem only I have.

Role
AI Product · built for myself
Who it’s for
Me — one user, one blog, one game-world ruleset
Job to be done
My daily quest list → storyboard + VO lines without 30 min of planning
Stack
Telegram webhook · Supabase Edge · Groq · Markdown knowledge base

Why I built it

I’m developing a Reels format for my own blog: daily life as an open-world game — five resources, unlocks, fog of war, Level 33. The idea is specific. Generic AI doesn’t know that drawing spends Inspiration or that my mug stays 🔒 until I find a job. ChatGPT suggests trend lip-sync; productivity apps give XP without shot structure.

My bottleneck was practical: every Reels took 30+ minutes just to plan — what to film, in what order, what to say, which sticker pop matches which quest. I wanted that plan in Telegram in under a minute, already aligned with how I actually shoot and edit.

  • Unique context — my resource economy, unlocks, and voice; not a reusable “creator template”
  • Hard constraints — iPhone 15 Pro, iMovie, headset mic; no CapCut fantasies
  • Honest scope — personal agent, allowlisted chat ID; not pretending this is a SaaS market

What it does

A Telegram bot with a revision loop I use every shooting day: send real quests, get JSON storyboard, tweak with /add or /rewrite. Output includes timecodes, on-screen text, a VO line per scene (my_thought), resource gain/spend, and one filming + one editing practice assignment for that Reels.

  1. /today — I send today’s real quests
  2. /storyboard — LLM reads my knowledge base → JSON
  3. /add · /rewrite — I refine without starting over
  4. Reply — scenes, +/− resources, 📚 one skill to practice on this Reels

Architecture

Portfolio case only — no public bot link. Production agent runs 24/7 on the same Supabase project as Resume Matching Agent.

  1. Telegram webhook → Supabase Edge Function (reels-agent)
  2. Postgres session state — quests, skill rotation, last storyboard
  3. Knowledge JSON served from GitHub Pages (versioned with portfolio)
  4. Groq LLM — JSON storyboard with fallback template
  5. Webhook secret + allowlisted chat IDs — personal use only

My knowledge base

The agent only works because the context is encoded — my game, my gear, my rules. Two layers, both personal:

Layer 1 · My game world

The resource system I designed for @sashaiamdrawing — gain and spend, not a generic streak counter.

  • Job search+15 Experience
  • Draw / craft− Inspiration
  • Chores / plants / pets− Energy
  • Publish Reels+25 Reputation

My unlocks — mug 🔒 until job, song cover progress — become narrative hooks in every storyboard.

Layer 2 · My Reels setup

What I actually own and how I edit — the model can’t suggest what I can’t shoot tomorrow.

  • 35 sec target · hook in first 2 sec · cut every 2–3 sec
  • Max 6 words on screen · 1.5–2 sec VO slot per scene (my_thought)
  • iPhone 15 Pro + iMovie · headset mic · PNG/GIF stickers
  • No trend lip-sync · no CapCut-only effects · no DaVinci (yet)

Live game progress

Resource totals and active quest investment — updated when I log a session in Telegram (/log, /log apply after storyboard).

Product decisions

Constraint-first generation

Hard-coded in Markdown — my iPhone, iMovie, mic, stickers. Stops the model from suggesting shots I can’t execute.

My voice in every scene

I asked for my_thought in each scene — a VO line in my words, not generic captions.

Learn while I publish

Each storyboard rotates the next shoot + edit skill — concrete assignments tied to that day’s scenes. I find my own learning material.

Serverless for one user

Supabase Edge webhook — same project as Resume Agent. Runs without my laptop; session state in Postgres.

Status

MVP live — I use it in Telegram daily. One allowlisted user, no public bot link on this site.

  • Storyboard in ~30 sec vs. half an hour of manual planning
  • Resource ledger in Telegram — /log remembers totals; portfolio page shows live bars
  • 8 Markdown files → compact JSON; updates when I change my game rules
  • What I’d prove next: publish Reels from agent output and measure reach vs. my baseline
