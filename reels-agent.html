Personal Product Vision · AI product + automation

Reels Agent

A personal AI agent that reads your day like a game, knows Reels format rules, and outputs a ready-to-shoot 35-second storyboard — tuned to your iPhone and iMovie setup.

User
@sashaiamdrawing — creator, Level 33
Problem
Turn real life into Reels without trend-chasing or generic templates
Solution
Telegram agent: quests → 5 resources → storyboard + video skills
Stack
Python · aiogram · Groq · knowledge base (Markdown)

Architecture

Portfolio case only — no public bot link. Live agent: Telegram webhook → Supabase Edge Function + Groq + Postgres session state (same Supabase project as Resume Agent).

  1. Telegram webhook → Supabase Edge Function
  2. Session in Postgres — quests, skill progress
  3. Knowledge JSON from GitHub Pages
  4. Groq LLM — storyboard JSON
  5. Reply — resources (+/−), scenes, 📚 learn-on-this-Reels

The idea

Real life as an open-world game — five resources (Experience, Energy, Inspiration, Reputation, Coins), not one “productivity score”. Drawing spends Inspiration; family movie gives it. The agent turns today’s quests into a 35-second storyboard for iPhone + iMovie — and one video skill to learn on each Reels.

Two knowledge layers

Layer 1 · Game world

Quests map to resources — gain or spend. Unlocks, fog of war, Level 33.

  • Job search+15 Experience
  • Draw / craft− Inspiration
  • Chores / plants− Energy

Example input:

  • Study Open World Design
  • Water flowers
  • Draw
  • Cook dinner
  • Go for a walk

Layer 2 · Reels format

The agent knows platform rules and what keeps attention — and only suggests effects you can actually do.

  • Up to 40 seconds; hook in the first 2 seconds
  • Cut every 2–3 seconds
  • Max 6 words on screen
  • Current trends, transitions, retention tricks

Your setup:

  • Shot on iPhone
  • Edit in iMovie
  • PNG stickers available

Example output · 35 sec storyboard

  1. 0–2 sec Hook

    “Today I need to earn 100 XP.”

  2. 2–6 sec Show planner

    Today’s quest list on screen.

  3. 6–12 sec Study timelapse

    Learning Open World Design — timelapse clip.

  4. 12–17 sec XP pop

    +15 Intelligence overlay.

  5. 17–23 sec Water plants

    Action shot — watering flowers.

  6. 23–28 sec XP pop

    +20 Nature XP overlay.

  7. 28–35 sec Day recap

    Total XP earned, mood, tomorrow’s hook tease.

Status

MVP live on Supabase Edge (personal Telegram, not linked from this site). Resource economy, Groq storyboard, learn-on-each-Reels.
