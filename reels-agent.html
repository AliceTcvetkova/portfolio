Personal Product Vision · AI product + automation

Reels Agent

A context-aware AI agent that closes the gap between what happened today and what to film — outputting a shoot-ready 35-second storyboard constrained by brand voice, game-world rules, and a real iPhone + iMovie workflow.

Role
AI Product · end-to-end builder
User
Creator (@sashaiamdrawing) — process-first Reels, Level 33 life-game
Job to be done
Daily quest list → structured storyboard + VO lines in under 2 minutes
Stack
Telegram webhook · Supabase Edge · Groq · Markdown knowledge base

Problem

Creators who treat life as an open-world game still hit a production bottleneck: turning an honest to-do list into a Reels plan that feels on-brand, respects platform pacing, and matches actual gear — without copying viral templates.

  • Generic AI → trend lip-sync ideas that contradict the creator’s positioning
  • Productivity apps → XP gamification without narrative or shot structure
  • Manual planning → 30+ minutes per Reels before filming starts

Solution

A personal Telegram agent with a revision loop: capture today’s quests, generate a JSON storyboard, iterate with natural-language edits. Output is production-ready — timecodes, on-screen text, VO thoughts, resource pops, and one filming + one editing skill per Reels.

  1. /today — user sends real quests (no fake tasks)
  2. /storyboard — LLM + knowledge base → structured JSON
  3. /add · /rewrite — refine without restarting the session
  4. Reply — scenes, resource gain/spend, 📚 learn-on-this-Reels block

Architecture

Portfolio case only — no public bot link. Production agent runs 24/7 on the same Supabase project as Resume Matching Agent.

  1. Telegram webhook → Supabase Edge Function (reels-agent)
  2. Postgres session state — quests, skill rotation, last storyboard
  3. Knowledge JSON served from GitHub Pages (versioned with portfolio)
  4. Groq LLM — JSON storyboard with fallback template
  5. Webhook secret + allowlisted chat IDs — personal use only

Dual knowledge base

Two constraint layers prevent generic “day in my life” output. The agent must satisfy both before suggesting a shot.

Layer 1 · Game world

Five resources with honest gain and spend rules — not a single productivity score.

  • Job search+15 Experience
  • Draw / craft− Inspiration
  • Chores / plants / pets− Energy
  • Publish Reels+25 Reputation

Unlocks & fog of war (e.g. mug 🔒 until job found) drive narrative hooks.

Layer 2 · Reels & setup

Platform format rules + creator constraints — only suggest what is actually feasible.

  • 35 sec target · hook in first 2 sec · cut every 2–3 sec
  • Max 6 words on screen · 1.5–2 sec VO slot per scene (my_thought)
  • iPhone 15 Pro + iMovie · headset mic · PNG/GIF stickers
  • No trend lip-sync · no CapCut-only effects · no DaVinci (yet)

Product decisions

Constraint-first generation

Hard-coded equipment and format rules in the knowledge base beat post-hoc filtering — the model never suggests shots the user cannot execute.

Author voice in every scene

Each scene reserves time for a first-person VO line (my_thought) — process and personality, not just B-roll captions.

Learn-on-each-Reels

Rotating queue of filming + editing skills from active courses — content production doubles as deliberate practice.

Serverless, not local polling

Edge Function webhook on free tier — shared infra with Resume Agent, no always-on laptop, session persistence in Postgres.

Example output · 35 sec storyboard

Input: five real quests. Output excerpt — scenes with resource economy and VO thoughts.

  1. 0–2 sec Hook

    📱 «Level 33 · сессия» · 🎙 «Level 33 — сегодня снова играю в свою жизнь.»

  2. 2–6 sec Quest list

    📱 «5 квестов» · 🎙 «Это не todo-list, а квесты на одну сессию.»

  3. 6–11 sec Study game design

    Timelapse B-roll · ⭐ −25 Experience · 🎙 «Учёба игре стоит опыта — и это ок.»

  4. 11–16 sec Water plants

    Action shot · ⭐ −8 Energy · sticker: plants

  5. 16–21 sec Draw

    Process clip · ⭐ −20 Inspiration · chain after cinema night if applicable

  6. 28–35 sec Recap + fog

    📱 «Кружка 🔒 до работы» · 🎙 «За туманом — кружка, когда найду работу.»

Plus video_learning block: one shoot skill + one edit skill tied to today’s scenes.

Status & outcomes

MVP live — personal Telegram agent on Supabase Edge, Groq-powered storyboards, revision commands, resource economy, VO slots, and per-Reels skill rotation.

  • Time to storyboard: ~30 sec (vs. manual planning)
  • Knowledge base: 8 Markdown sources → compact JSON for Edge runtime
  • Next: few-shot examples from published Reels, sticker preview in chat
