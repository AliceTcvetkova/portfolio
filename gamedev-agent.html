Why I built it

I’m transitioning to game product management and building my own game — exploration + world restoration with dual progression (character + world). Generic AI treats every session as a blank slate: it suggests new genres, rewrites my core loop, or gives answers instead of teaching me to think like a designer.

My bottleneck: I need structured learning (MDA, economy, open world) parallel to Unreal and Blender — with homework checked strictly, progress tracked, and theory applied to one game concept I’ve already committed to.

  • Fixed source of truth — established decisions vs hypotheses vs open questions
  • Teaching mode — asks me to analyze first; doesn’t dump finished GDD paragraphs
  • Three tracks — game design curriculum + ProductStar Unreal + Blender via YouTube

My game (source of truth)

The agent reads a locked Game Design Brief — it must not redesign unless I explicitly ask.

Player fantasy

“I don’t just level up — I gradually return life to a damaged world and see the consequences of my actions.”

Dual progression

  • Character — abilities, tools, access to harder areas
  • World — cleaner, livelier, new NPCs/areas/content from restoration

Two core loops — the second is the differentiator:

Player loop

Explore → Encounter problem → Act → Reward → Improve → Explore new areas

World loop

Player action → World changes → New world state → New exploration possibilities
🔒 Established 🔬 Hypothesis ❓ Open question 💡 Recommendation

What it does

A Cursor skill + local workspace. I open gamedev-agent, say one phrase, get one focused session.

  1. “I'm ready to learn” — today’s topic, materials, assignment, apply-to-my-game task
  2. “Review my assignment” — score /10, specific feedback, pass threshold ≥7
  3. “Apply to my game” — practical exercise on restoration concept
  4. “Blender lesson” — YouTube self-study: topic + deliverable, I pick the video

Knowledge base

The agent only works because context is encoded — my game brief, curriculum, course tracks, rubric.

Layer 1 · Game Design Brief

Identity, player fantasy, dual loops, design principles — locked. Agent checks new mechanics against 9-point checklist and principles 1–7.

  • Progression must create visible world consequences
  • Abilities unlock possibilities, not just numbers
  • World restoration reveals content — not cosmetic only

Layer 2 · Curriculum & courses

5 levels: fundamentals → open world → economy → production → prototype. Parallel tracks:

  • Unreal — ProductStar (104 lessons mapped, P0+P1 for prototype)
  • Blender — 14 YouTube assignments → damaged/restored props
  • Schedule — GD Mon/Wed/Fri · UE Tue/Thu · Blender Sat

Product decisions

No blank-slate ideation

Recommendations are labeled 💡 — never promoted to canon without my confirmation.

Strict review

Motivation ≠ action. Mechanics ≠ dynamics. Failed homework = rework, not checkmark.

PM-native format

Frameworks, tables, checkpoints — leverages my product background instead of dumbing down.

Outcome = GDD + prototype

Months of sessions → filled gdd.md + Unreal vertical slice (explore, restore, see world change).
