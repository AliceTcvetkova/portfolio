AI Resume Matching Agent

A multi-agent pipeline that reads a vacancy, matches it to my experience, and produces a tailored CV — built as a portfolio product demo.

User
Recruiter / Hiring Manager
Problem
Finding relevant experience quickly
Solution
AI-powered matching and CV adaptation
Tech
LLM + Supabase + Prompt Engineering

How it works

Six specialized agents run in sequence — parser, matcher, CV tailor, recruiter validator, cover letter writer (internal), and QA scorer. The public demo exposes match analysis and CV generation only.

  1. Parse vacancy → must-have, keywords
  2. Match against Ozon, VK, IRPO, Erich Krause + case studies
  3. Tailor CV bullets to vacancy language
  4. Validate ATS + recruiter rules

Try it

Paste a job URL or full vacancy text. The agent compares it to my structured experience base.
